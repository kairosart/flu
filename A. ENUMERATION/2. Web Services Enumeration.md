The two unidentified ports from the scan (`8090` and `8091`) were fingerprinted by sending raw HTTP requests and comparing responses. Neither matched Nmap's service guesses — both are web-based and must be identified manually.

## 8090/tcp — Atlassian Confluence 7.13.6

Sending a raw `GET /` immediately identifies the application via its headers and redirect.

```bash
printf 'GET / HTTP/1.1\r\nHost: 192.168.173.41\r\nUser-Agent: Mozilla/5.0\r\nConnection: close\r\n\r\n' | nc 192.168.173.41 8090
```

```
HTTP/1.1 302
Cache-Control: no-store
X-Confluence-Request-Time: 1791570981029
Set-Cookie: JSESSIONID=6B3CD19B6500562AF4824F2BB7DBB82C; Path=/; HttpOnly
X-XSS-Protection: 1; mode=block
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
Content-Security-Policy: frame-ancestors 'self'
Location: /login.action?os_destination=%2Findex.action&permissionViolation=true
Content-Type: text/html;charset=UTF-8
Date: Fri, 09 Oct 2026 18:36:21 GMT
```

Identifiers:

- `X-Confluence-Request-Time` and the `JSESSIONID` cookie → **Atlassian Confluence**.
- `Location: /login.action?...&permissionViolation=true` → anonymous access is not permitted; a login is required.

### Version Fingerprinting

The exact version is embedded in the login page's meta tags.

```bash
curl -s http://192.168.173.41:8090/login.action | grep -oiE 'ajs-version-number[^>]*|Confluence [0-9.]+'
```

```
ajs-version-number" content="7.13.6"
Confluence 7.13.6
```

The login page also leaks the configured **base URL**, revealing an internal hostname/IP:

```
confluence-base-url" name="confluence-base-url" content="http://192.168.226.170
```

### Analysis

**Confluence 7.13.6** is affected by **CVE-2022-26134**, a critical, **unauthenticated OGNL template-injection** vulnerability leading to Remote Code Execution. The version is *below* the fixed `7.13.7` release, so it is in scope for exploitation.

## 8091/tcp — Custom App on Clojure "Aleph" HTTP Server

This port behaves very unusually: it returns **`204 No Content` for every request**, regardless of path or method, with a `Server: Aleph/0.4.6` header. ("Aleph" is a Clojure HTTP web server library — this is the framework name, not the application.)

```bash
curl -s -i http://192.168.173.41:8091/
```

```
HTTP/1.1 204 No Content
Server: Aleph/0.4.6
Date: Fri, 09 Oct 2026 18:36:34 GMT
Connection: Keep-Alive
```

### Method Discovery

An `OPTIONS` request reveals the allowed methods and a permissive CORS policy.

```bash
curl -s -i -X OPTIONS http://192.168.173.41:8091/
```

```
HTTP/1.1 200 OK
Access-Control-Allow-Origin: *
Access-Control-Max-Age: 31536000
Access-Control-Allow-Methods: OPTIONS, GET, PUT, POST
Server: Aleph/0.4.6
content-length: 0
```

- Allowed verbs: `OPTIONS, GET, PUT, POST`.
- `Access-Control-Allow-Origin: *` → the API may be callable cross-origin.

### Endpoint Fuzzing

Because everything returns a uniform `204`, directory/endpoint discovery uses the status code as a filter.

```bash
ffuf -u http://192.168.173.41:8091/FUZZ -w /usr/share/wordlists/dirb/common.txt -fc 204 -mc all -t 60
```

Also probed common API paths and all three verbs manually:

| Verb | Paths tried | Result |
|------|-------------|--------|
| GET | `/`, `/api`, `/api/1`, `/api/2`, `/api/v1`, `/graphql`, `/query`, `/health`, `/status`, `/metrics`, `/login`, `/robots.txt` | all `204` |
| POST | same set | all `204` |
| PUT | same set | all `204` |

- **`ffuf` over `common.txt` (4,614 words): 0 hits.** No path returns anything other than `204`.
- No readable content, no version banner body, no error pages.
- Host header variations (`localhost`, `aleph`, the IP) made no difference.

### Analysis

Port `8091` is a **black-box service that leaks nothing** — effectively a dead end for reconnaissance. It is documented as a red herring rather than part of the intended attack path.

## Summary

- **8090/tcp** → **Atlassian Confluence 7.13.6** → vulnerable to **CVE-2022-26134** (unauthenticated OGNL injection → RCE). **This is the initial-access vector.**
- **8091/tcp** → custom Clojure/"Aleph" service returning `204` to everything, with permissive CORS. No endpoints or content could be discovered → treated as a **decoy / dead end**.
- Internal base URL `192.168.226.170` leaked by Confluence is worth noting for any later pivoting.
